WinGridds 11 — Command Reference

A modern re-creation of the WINGRIDDS / PCGRIDDS32 command language. Commands are case-insensitive; overlay multiple fields with & (or +).

Field parameters

HGHT lvlGeopotential height (m). Default contour intervals: 30 m at/below 700, 60 m at 500, 120 m at 300/250/200.
TEMP lvlTemperature (°C). Sub-zero contours are dashed. Add FILL for a color-shaded field.
DWPT lvlDewpoint (°C), computed from temperature and relative humidity.
RELH lvlRelative humidity (%). Classic look: RELH 700 FILL.
WIND lvlWind barbs (kt), drawn on a thinned grid.
SPED lvlIsotachs / wind speed (kt). SPED 300 FILL shows the jet.
VORT lvlAbsolute vorticity (10⁻⁵ s⁻¹). RVRT gives relative vorticity.
DVRG lvlDivergence (10⁻⁵ s⁻¹), diverging color scale when filled.
TADV lvlTemperature advection (°C / 3 h). Warm advection positive.
VADV lvlAbsolute vorticity advection (10⁻⁹ s⁻²).
THCK1000–500 hPa thickness (m). Classic: PMSL CI4 HILO & THCK CI60 DASH. The 5400 m contour is emphasized.
PMSLMean sea-level pressure (hPa).
T2M / D2M2-m temperature / dewpoint (°C).
CAPESurface-based CAPE (J/kg).
PRCPPrecipitation rate at the valid time (mm/h).

Levels

Any of 1000 925 850 700 500 400 300 250 200 hPa; surface parameters (PMSL, CAPE, PRCP, T2M, D2M, THCK) need no level. A bare number sets the level for the parameter before it, e.g. HGHT 500.

Style modifiers (per overlay)

CIn (e.g. CI60, CI4)Contour interval in the field's display units.
FILLColor-shaded (filled) field instead of line contours; a legend is drawn.
LINEForce line contours (default).
BARBWind barbs (only meaningful with WIND).
DASHDashed contours.
HILOMark local maxima/minima with H / L and their values.
CLR1…CLR6Contour color slot: 1 white/ink, 2 yellow, 3 cyan, 4 magenta, 5 green, 6 orange.
SMTHExtra smoothing pass on the field.

Global commands

Fhh (e.g. F048)Jump to a forecast hour (6-h steps, F000–F168).
LOOPToggle animation through all forecast hours.
MAPDraw the base map only.
HELPOpen this reference.

Keyboard

Data

Live mode ingests NCEP GFS model output through the free Open-Meteo API (no key required) on a grid covering the chosen domain, out to +168 h in 6-h steps. Forecast-hour labels are referenced to today's 00 UTC cycle as presented by the API. If the network is unavailable the app switches to a physically plausible synthetic demo dataset so every command still works.

WINGRIDDS is freeware by Jeff Krob (winweather.org). This project is an independent, unofficial tribute that re-implements the concept and command style for modern systems; it shares no code with the original.
